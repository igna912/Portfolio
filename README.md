## Proyectos

### 01. FUTGO – Aplicación web Full Stack

Proyecto universitario orientado a la búsqueda y organización de partidos de fútbol.

**Tecnologías utilizadas:**
- Frontend: React, TypeScript, Vite y Tailwind CSS.
- Backend: Node.js, Express y TypeScript.
- Base de datos: PostgreSQL.
- ORM: Prisma.

**Repositorios:**
